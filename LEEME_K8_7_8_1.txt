K.8.7.8.1 — Workspace Routing Hotfix

Causa:
K.8.7.8 retiró accidentalmente del URLconf ocho rutas del workspace actual al retirar las rutas legacy de ExpedienteServicio.

Este hotfix RESTAURA únicamente:
- crear tema
- enviar mensaje
- guardar referencia
- eliminar adjunto
- eliminar mensaje
- limpiar historial de canal
- eliminar referencia
- archivar tema

Las rutas legacy de ExpedienteServicio siguen retiradas.

No modifica:
- modelos
- migraciones
- base de datos
- Builder
- templates
- servicios
- permisos
- media

Aplicación:
Copiar el CONTENIDO de K8_7_8_1_HOTFIX sobre la raíz del proyecto K.8.7.8.

Ejecutar primero:
  python scripts/verify_hotfix_k8_7_8_1.py

Si termina OK, ejecutar:
  python scripts/verify_stable_k8_7_8.py

No hacer commit/tag todavía hasta que el stable gate completo termine OK.
