# Canvas Workspace

Versión: 1

El Canvas Workspace conecta el Documento migrado con la nueva interfaz Django.

## Funciones disponibles

- seleccionar lienzo;
- crear lienzo;
- duplicar;
- eliminar;
- subir y bajar;
- mostrar u ocultar;
- renombrar;
- conservar la selección en `WorkspaceState`;
- render básico de nodos TEXT, IMAGE, VIDEO, BUTTON, CARD, CONTAINER y COUNTDOWN.

## Límites actuales

- No existe todavía selección de nodos.
- No hay drag & drop ni resize.
- El Inspector solo cambia el nombre del lienzo.
- El preview es una representación inicial; el Universal Renderer completo se conecta después.
