# Biblioteca visual de componentes

Versión: 1

## Componentes disponibles

- Título
- Subtítulo
- Párrafo
- Botón
- Imagen
- Video
- Card
- Contenedor
- Countdown
- Separador

## Inserción

Los elementos pueden agregarse:

1. Con un clic, usando una posición inicial escalonada.
2. Arrastrándolos desde la biblioteca hasta un punto del lienzo.

Después de insertar:

- el nodo queda seleccionado;
- aparece en Capas;
- aparece en el Inspector;
- puede moverse, redimensionarse y rotarse;
- forma parte del Documento y del historial.

Imagen y Video se crean como placeholders. La selección y subida del archivo se conecta en Sprint 10.8.
