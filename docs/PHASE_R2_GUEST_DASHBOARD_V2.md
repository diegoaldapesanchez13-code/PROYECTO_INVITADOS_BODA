# PHASE R.2 — Guest Dashboard V2

R.2 replaces the legacy 12-column guests table with a card workspace.

Contract:
- Grupoinvitacion = grouping/link/contact.
- Invitado = person/RSVP/buffet/table.
- PERSONAL has one nominal guest plus organizer-authorized optional extras.
- FAMILIAR contains named people plus optional extra placeholders.
- Guest UI does not expose allergies, dietary restrictions or food requests.
- Adult/child and buffet assignment remain organizer-owned.
- Public RSVP is intentionally unchanged until R.3.
